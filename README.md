
# Portfolio Website 

This is my personal portfolio built using React.js. It showcases my skills, projects, and contact information in a clean, responsive design.

---

## Features

- Home page with introduction and navigation
- About page with bio, skills, and profile image
- Projects page featuring:
  - React To-Do App (GitHub project)
  - Figma UI/UX design project
  - GIF animation project
- Contact page with:
  - Social media links
  - Instagram QR code

---

## Built With

- React.js
- JavaScript
- React Router
- CSS (inline styling)
- Git & GitHub
